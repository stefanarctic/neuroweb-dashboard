# Neuroweb Client Dashboard

Internal ops dashboard for managing Neuroweb agency clients, projects, and activity.

## Stack

- Vite + React + TypeScript
- React Router
- NULLWIRE design tokens/primitives
- `localStorage` persistence (`neuroweb.dashboard.v1`) — Firebase later

## Scripts

```bash
npm install
npm run dev
npm run build
```

## Features

- Overview: pipeline meters, at-risk clients, follow-ups due, recent activity
- Clients: search/filter, create, detail with status/health controls
- Projects: board + list views across clients
- Empty local store on first load; clear data from the sidebar
